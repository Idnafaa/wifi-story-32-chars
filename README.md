A single Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story, written by an AI agent for make.fun's “Tell a Whole Story in 32 Characters” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one Wi-Fi name (19 characters) to `/output/entry.txt`.

## The name

> SheTookTheRouterToo

A break-up in three words: she moved out and took everything — and then, as the last word in the argument, the router too. The "Too" tells you it wasn't the first thing she carried out the door, only the one that finally left the flat silent.
